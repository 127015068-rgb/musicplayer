# 🎵 MERN Stack Music Player Web Application

A full-stack **Music Player Web Application** built using the **MERN Stack (MongoDB, Express.js, React.js, Node.js)** during my internship at @Web Stack Academy.

This project demonstrates complete frontend, backend, and database integration with real-world features like authentication, playlists, and audio streaming.

---

🎥 YouTube Presentation: https://youtu.be/jpQUJNL5f2A

## ✨ Features

✅ User Authentication (JWT Login/Signup)  
✅ Play / Pause / Next / Previous controls  
✅ Song progress bar & seek functionality  
✅ Playlist creation & management  
✅ Song upload & streaming  
✅ Responsive modern UI  
✅ RESTful API integration  
✅ Secure backend with Node & Express  
✅ MongoDB database storage
